# Privacy and legal notice

Last updated: 27 November 2026. [Versione italiana](#informativa-in-italiano) below.

This notice covers **www.caddy-waf.com**, the documentation site of the caddy-waf project.

## Who publishes this site

**Fabrizio Salmi**, Genoa, Italy, is the data controller. This is a personal, non-commercial
open-source project site. Privacy requests: [fabrizio.salmi@gmail.com](mailto:fabrizio.salmi@gmail.com).

## Hosting

The pages are hosted by **GitHub, Inc.** (USA) through GitHub Pages. Delivering a page means
GitHub processes your IP address and basic request data (user agent, page requested) to serve it
and protect it against abuse. We do not receive these logs.

## Page-view statistics

The site counts visits with **Umami**, an open-source analytics tool, running on an instance
run by the publisher at `umami.edge99.net`. No analytics company receives the data.

For each page view the script sends: the page address (including any query string, such as UTM
campaign tags), page title, referring page, browser, operating system, device type, screen size
and browser language. From your IP address the server derives the country, region and city, and
a session identifier computed with a one-way hash. **The IP address itself is not stored.** No
name, email or account is involved, the data is not combined with other sources, and it is used
only to see which pages are read and where readers come from.

The instance is reached through **Cloudflare, Inc.** (USA), which forwards the request and
therefore sees your IP address in transit.

Retention: the statistics are kept on the instance until deleted. Database backups are kept for
14 days.

## Cookies and device storage

The site sets **no cookies**, so there is no consent banner.

- The theme remembers your light or dark choice in `localStorage` under
  `vitepress-theme-appearance`. It stays on your device and is never sent anywhere.
- The statistics script stores nothing on your device. It only reads one `localStorage` key,
  `umami.disabled`: if it is set, nothing is sent. To opt out in this browser, open the developer
  console on this site and run `localStorage.setItem('umami.disabled', '1')`.

## Legal basis and transfers

Hosting and statistics rely on legitimate interest (Art. 6(1)(f) GDPR): delivering the site,
keeping it secure, and knowing which documentation is used. Transfers to GitHub and Cloudflare in
the USA rely on the EU-US Data Privacy Framework and the providers' Standard Contractual Clauses.

## Your rights

You have the rights of access, rectification, erasure, restriction, objection and portability
